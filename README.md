Project-UTS Pemrograman Berbasis Web Kelompok 4

Tema: Kos & Apartemen Hunter: Aplikasi untuk membantu mahasiswa baru mencari dan membandingkan informasi tempat tinggal (kos, kontrakan, apartemen) di sekitar kampus.

Project yang dibuat menggunakan fitur peta dan grafik untuk memudahkan mahasiswa mencari lokasi hunian terdekat dari kampus sekaligus menampilkan rute terdekat dari hunian ke kampus, untuk grafik menampilkan rata-rata harga per bulan dan menampilkan grafik perbandingan harga antara hunian agar mahasiswa bisa memilih antara kos, kontrakan, atau apartemen yang ingin di sewa lalu disitu juga ada harga untuk tiap hunian
